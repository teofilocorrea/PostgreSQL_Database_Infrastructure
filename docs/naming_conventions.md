# Convenciones de nombres

## 📌 Objetivo

Definir las reglas de nomenclatura utilizadas en la base de datos para garantizar consistencia, claridad y mantenibilidad en la estructura del proyecto.

Estas convenciones serán aplicadas progresivamente a medida que el modelo evolucione.

---

## 🧠 Principios generales

- Uso de **snake_case** (palabras separadas por guion bajo `_`)
- Todos los nombres deben estar en **minúsculas**
- Evitar espacios y caracteres especiales
- Utilizar nombres **descriptivos y claros**
- Mantener consistencia en todo el proyecto
